# 🍔 EatUp – Food Delivery Web App

🚀 A modern food delivery web application built with **Next.js, React, and Tailwind CSS**, focused on clean UI, smooth user experience, and interactive features.

---

## 📝 Description

EatUp is a frontend-focused food delivery platform where users can browse menus, manage carts, and track orders in a responsive and visually appealing interface.
